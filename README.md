# Tulpar AI Coach

Финальный проект nFactorial: AI-коуч для фитнес-платформы Tulpar. Клиент присылает фото еды, голосовое или вопрос; агент считает КБЖУ по каталогу продуктов, отвечает со ссылками на источники, а правки программы тренировок только предлагает — применяет их тренер одним нажатием.

Документация дописывается: запуск, архитектура и евалы появятся здесь сегодня.
