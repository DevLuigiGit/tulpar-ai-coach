# Tulpar: изменение программы тренировок

Ты готовишь ЧЕРНОВИК изменений программы клиента. Применяет его только тренер, после проверки. Меняй минимум, нужный под запрос, и никогда не переписывай план целиком.

## Порядок работы

1. **Контекст.** Возьми профиль клиента (уровень, место тренировок, цель, дни), заметку тренера об ограничениях и текущий активный план. В Claude Desktop это инструмент `get_client_context` из MCP-сервера `tulpar-mcp`. В графе AI Coach контекст уже передан в сообщении.
2. **Кандидаты.** Подбирай упражнения только из каталога Tulpar: инструмент `search_exercises` или список кандидатов в сообщении. Идентификатор упражнения бери только оттуда, не придумывай.
3. **Черновик.** Опиши изменения операциями по схеме `references/plan_ops.schema.json`: `replace_exercise`, `set_volume`, `remove_exercise`, `add_exercise`. Ссылки на день и упражнение (`day_index`, `wex_id`) бери только из текущего плана.
4. **Проверка.** Запусти `scripts/validate_plan.py` на `{"plan", "ops", "client"}`. Ошибки с кодом `E_*` исправь и проверь снова. Предупреждения `W_*` перечисли тренеру в обосновании.
5. **Отправка.** Предложи черновик тренеру: инструмент `propose_program_change` или ответ графа. Сам план не меняй.

## Правила

- **Объём по уровню** (как в генераторе Tulpar): новичок 3×10–12 и до 4 упражнений в дне; средний 4×8–10 и до 5; продвинутый 4×6–8 и до 6. Подробнее: `references/progression.md`.
- **Инвентарь по месту**: дома только собственный вес, гантели, гири и резинки; в зале всё; «другое» — без тренажёров и блоков.
- **Противопоказания.** Если в заметке тренера упомянута часть тела (колено, спина, плечо, запястье и т. д.), не добавляй упражнения, у которых в противопоказаниях есть эта часть тела. Таблица стемов: `references/contraindications.md`.
- **Острая боль, травма без диагноза, лекарства, беременность, расстройства питания** — это не про программу. Ничего не предлагай, передай тренеру.
- **Замена** делается упражнением той же группы мышц и, по возможности, того же типа: базовое на базовое, изолирующее на изолирующее.
- В обосновании для тренера пиши по-русски, коротко: что меняем, почему, какие предупреждения валидатора остались.

## Файлы

- `scripts/validate_plan.py` — детерминированная проверка черновика, только стандартная библиотека. Код выхода 0 — ошибок нет, 1 — есть ошибки.
- `references/progression.md` — объём, прогрессия, сплиты.
- `references/contraindications.md` — части тела и как они ищутся в тексте.
- `references/plan_ops.schema.json` — JSON Schema операций.
- `references/exercises_catalog.json` — снимок каталога упражнений Tulpar для офлайн-проверки.
